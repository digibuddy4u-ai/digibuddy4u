# DigiBuddy4U — Admin Dashboard

Modern, responsive web dashboard for DigiBuddy4U agency management.

## Tech Stack
- **Framework**: React 19 with Vite 8
- **Styling**: Tailwind CSS 3.4
- **Routing**: React Router DOM 7
- **Icons**: Lucide React
- **Design System**: Brand Deep Navy, Electric Blue, Cyan, Yellow accents, Poppins & Inter typography.

## Setup & Running

```bash
cd admin
npm install
npm run dev
```
Dashboard will run at **http://localhost:3001/**.
